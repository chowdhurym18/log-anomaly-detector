## 8. Evidence-based recommendations

- **Keep MSP as the uncertainty signal** — it has the best (or tied) AUC (0.8725); top-2 gap and 1−entropy do not beat it meaningfully.
- **Confidence is reasonably calibrated** (avg gap 0.09); raw thresholds are trustworthy as-is.
- **Keep the 0.70/0.40 thresholds** — accuracy falls monotonically across the bands (94.4% → 61.5% → 47.1%) with a large NORMAL→UNCERTAIN drop, so the routing cleanly separates easy from hard cases. The threshold study shows raising the cutoffs (Set B/C) mainly increases Llama load for a small NORMAL-band accuracy gain.
- **The 1B model adds little narrative value right now** — only 1/20 sampled narratives survived scrubbing; the rest fell back to the deterministic template text. The safeguards are working as intended, but llama3.2:1b's free-text is mostly discarded as ungrounded/speculative — consider a larger Ollama model, or accept the deterministic narrative and drop the LLM call to save the ~14.9s/case latency.
- **Explanation safeguards hold** — all 20 sampled narratives were evidence-clean; no architectural change needed for hallucination control.
- Attention-assisted explanations are only available with the `bigru_attention` variant; not applicable to the current `gru` model.
